# Лист персонажа

### Шапка листа — header

* header.name - соответствует наименованию character в списке foundry. Подпись над полем “Имя”
* header.role - текстовое поле ввода. ограничение - ввод не более 40 символов. Размер шрифта - 14. Подпись над полем “Роль”
* header.experience - блок с 12 чекбоксами. По нажатию на чекбокс после первого заполняются все чекбоксы до нажатого, включая нажаты. Аналогичное поведение при нажатии на активный чекбокс, если после нажатого чекбокса есть другие активные чекбоксы они должны быть сняты. Подпись над полем “Опыт”
* header.logo - Логотип, некликабельный,встраивается как изображение, отступ слева от блока header.role статичный,отступ справа до кнопок плавающий, зависит от разрешения экрана. Если отступ справа становится меньше отступа слева - лого скрывается.
* header.subtitle - текстовая подпись “Личное дело агента”

2\. Характеристики — attributes
Заголовок блока: “Характеристики”
Текстовые метки над блоком значений атрибутов “Макс.”, “Тек.” над одним и вторым столбцом соответственно.
Четыре строки характеристики. Каждая строка представляет из себя:
Название характеристики; Числовое поле ввода максимального значения; Числовое поле ввода текущего значения.
Название характеристик и их алиас: strength — Сила, agility — Ловкость, mind — Разум, empathy — Эмпатия.
У каждой характеристики есть значение атрибута:
• attributes.{name}.max — максимальное значение, числовое поле ввода, невозможно ввести значение меньше 0 и больше 5;
• attributes.{name}.current — текущее значение, числовое поле ввода, невозможно ввести значение меньше 0 и больше attributes.{name}.max; При изменении значения выполняется пересчет значений .dice в блоке skills.
3. Навыки — skills
Заголовок блока: “Навыки”
skills.add — Нажимаемая кнопка с изображением плюса и текстом Добавить, по нажатию добавляется строка skills.row
skills.settings — Нажимаемая кнопка с изображением шестеренки. По нажатию - выполняется переключение состояния блока skills. Заменяется отображение дополнительных строк:  skills.row.{name}.level и skills.row.{name}.dice заменяются на кнопку skills.custom.delete и обратно. Состояние по умолчанию: отображается skills.row.{name}.level и skills.row.{name}.dice.
Текстовые метки над столбцами навыков “Навык”, “Характеристика”,”Уровень”, “Кубы”  над каждым полем соответственно.
Строки навыков, содержащий два блока “Стандартные навыки” и “Дополнительные строки”. Стандартные навыки всегда отображаются и их поведение не зависит от нажатия кнопки skills.settings, Дополнительные строки - по умолчанию не отображаются, каждое нажатие кнопки skills.add создает новую строку. Ограничений по количеству строк нет, в случае достижения конца блока skills - размер блока растягивается по высоте, чтобы вместить новую строку. Соответственно блок general смещается ниже.
Каждая строка skills.row.{name} представляет собой перечень полей:
• .dragHandle - по зажатию левой кнопки мыши на элементе - позволяет менять порядок строк навыков в рамках блока skills с помощью перетаскивания.
• .name - название навыка. Текстовое поле ввода, не более 40 символов. Стандартные навыки заполняются заданными значениями, перечень заданных значений будет указан в конце описания блока skills. Название переменных для навыков задаются следующим образом: стандартные - имеют заранее определенные значения, дополнительные - задаются при создании новой строки, название формируется как статичное название {addskill} и порядковый номер строки. т.е. для первой дополнительной строки будет: {addskill\_1}
• .attribute - выпадающий список, содержащий закрытый перечень характеристик из блока attributes. Значения связаны напрямую, выбор характеристики в выпадающем списке подтягивает значение attributes.{name}.current выбранной характеристики для расчета значения .dice. Порядок элементов идентичен блоку attributes. После выбора значения выполняется пересчет значения .dice для данной строки.
• .level - уровень владения, числовое поле ввода, невозможно ввести значение меньше 0 и больше 99;
• .dice - количество кубов для броска, автоматически рассчитываемое значение. Расчет выполняется по формуле attributes.{name}.current + .level. По нажатию на аттрибут или на значение кубов выполняется бросок Nd6, где N - количество кубов.
Дополнительные строки в состоянии настройки - заменяются поля  .level и .dice на кнопку skills.custom.delete.
• skills.custom.delete - Нажимаемая кнопка с изображением корзины и текстом “Удалить”, по нажатию - текущая строка удаляется, а остальные дополнительные строки, если они существуют, смещаются вверх.
Название переменных для стандартных навыков:
• Атлетика - athletics, характеристика по умолчанию -  strength
• Ближний бой - melee, характеристика по умолчанию -  strength
• Выносливость - endurance, характеристика по умолчанию -  strength
• Скрытность - stealth, характеристика по умолчанию -  agility
• Ловкость рук - sleightOfHand, характеристика по умолчанию -  agility
• Стрельба - shooting, характеристика по умолчанию -  agility
• Медицина - medicine, характеристика по умолчанию -  mind
• Выживание - survival, характеристика по умолчанию -  mind
• Расследование - investigation, характеристика по умолчанию -  mind
• Проницательность - insight, характеристика по умолчанию -  empathy
• Выступление - performance, характеристика по умолчанию -  empathy
• Влияние - influence, характеристика по умолчанию -  empathy.

Настройки - settings
В стандартные настройки внутри системы Foundry добавляются следующие элементы настройки:
Пункт настроек: "Правила мира", содержит логические переключатели:
• settings.magic - магия;
• settings.will - воля;
• settings.radiation - радиация;
• settings.infection - заражение;
• settings.stress - уровень стресса.
У каждого переключателя:
• .label — подпись. Текстовое название параметра (указано соответствие выше);
• .toggle —  переключатель;
• .toggle.state — состояние inactive или active. Если состояние inactive, то соответствующий блок не отображается в Основном блоке, если active, то - отображается.
