# Point Zero

Система для Foundry VTT 14. Лист персонажа основан на правилах Year Zero Engine SRD, а также включает часть механик из открытых правил Free League основанных на этом движке.

Модуль разработан со значительным использованием ИИ!

## Доступный функционал

- Создание листа персонажа с изображением и токеном.
- Таланты, оружие, броня, снаряжение и заклинания представлены в виде предметов, могут быть изменены, добавлены, удалены и переставлены в желаемом порядке.
- В карточке таланта свёрнутый блок «Дополнительно» содержит необязательный «ID для связи» (до 64 символов: латинские буквы, цифры, `_` и `-`). Поле «Школа магии» в начале карточки заклинания хранит тот же ID. Связь учитывает регистр и игнорирует пробелы по краям; при нескольких подходящих талантах берётся наибольший уровень.
- Владелец персонажа может произнести заклинание из листа. Нужен талант соответствующей школы; заклинание на один ранг выше уровня школы вызывает обязательное осложнение, ещё выше — недоступно. Расход Воли выбирается в диалоге (минимум 1); он определяет базовую силу и исходное количество d6. Флажок «Не требует трат воли» в карточке заклинания дает базовую силу и исходные кубы по рангу заклинания без списания ресурса.
- Безопасное колдовство по выбору уменьшает число кубов на превышение уровня школы над рангом заклинания, вплоть до нуля; сила и стоимость сохраняются. Каждая шестёрка увеличивает силу на 1, единицы или превышение ранга вызывают одно осложнение. Push для магии не предусмотрен. Чат показывает силу, расход, кубы и результат D66 по 12 строкам [Year Zero Engine SRD, стр. 31](https://freeleaguepublishing.com/wp-content/uploads/2023/11/YZE-Standard-Reference-Document.pdf#page=31). Урон, стресс, травмы, состояния и дополнительные броски последствий выполняет ведущий; восстановление Воли ручное. Гримуары и автоматические эффекты заклинаний пока не реализованы.
- Дополнительные трекеры Воли, Радиации, Заражения и Стресса, а также отдельная вкладка магии. Включаются мастером в настройках Foundry.
- Лист персонажа поддерживает светлую и тёмную темы Foundry.
- Счётчик Doom Points можно перемещать по экрану. Ведущий меняет значение круглыми кнопками «−» и «+» или вводит число напрямую; изменения сохраняются без сообщений в чате.

## Установка и обновление

Адрес манифеста: `https://raw.githubusercontent.com/gorohovDM/PointZero/main/system.json`.

Есть отдельный тестовый канал: `https://raw.githubusercontent.com/gorohovDM/PointZero/test-channel/system.json`. Установите систему по этому адресу один раз, затем обновляйте её через Foundry.
