# Point Zero

Система для Foundry VTT 14. Лист персонажа основан на правилах Year Zero Engine SRD, а также включает часть механик из открытых правил Free League основанных на этом движке.

Модуль разработан со значительным использованием ИИ!

## Доступный функционал

- Создание листа персонажа с изображением и токеном.
- Таланты, оружие, броня, снаряжение и заклинания представлены в виде предметов, могут быть изменены, добавлены, удалены и переставлены в желаемом порядке.
- Дополнительные трекеры Воли, Радиации, Заражения и Стресса, а также отдельная вкладка магии. Включаются мастером в настройках Foundry.
- Лист персонажа поддерживает светлую и тёмную темы Foundry.
- Счётчик Doom Points можно перемещать по экрану. Ведущий меняет значение круглыми кнопками «−» и «+» или вводит число напрямую; изменения сохраняются без сообщений в чате.

## Установка и обновление

Адрес манифеста: `https://raw.githubusercontent.com/gorohovDM/PointZero/main/system.json`.

Для проверки изменений в локальном Foundry есть отдельный тестовый канал: `https://raw.githubusercontent.com/gorohovDM/PointZero/test-channel/system.json`. Установите систему по этому адресу один раз, затем обновляйте её через Foundry. Ветка `test` собирается после интеграции актуальных `main` и проверенного `codex/dev`; каждый push запускает регрессионные тесты и создаёт отдельный GitHub prerelease. Постоянный манифест в служебной ветке `test-channel` обновляется только после успешной публикации архива. Исходный `system.json` сохраняет стабильные ссылки.

Тестовая версия получает номер вида `0.2.7.<номер запуска>.<попытка>`; повторный запуск создаёт новый архив. Тестируйте на копии мира: обновление или откат системы не возвращает данные мира в прежнее состояние. Для перехода на стабильный канал нужно отдельно сменить источник установки. Публикация в `main` выполняется только по отдельному прямому запросу владельца проекта.
