# Point Zero

Система для Foundry VTT 14. Лист персонажа основан на механике Year Zero Engine.

## Использование

- Создайте актёра типа `character`. Поля персонажа сохраняются автоматически.
- Вкладки разделяют основной блок, снаряжение, магию, биографию и заметки. Вкладка магии появляется после включения одноимённого правила мира.
- Таланты, оружие, броня, снаряжение и заклинания хранятся как встроенные Items актёра. Создайте Item нужного типа в каталоге Foundry и перенесите его на актёра. Поля редактируются в листе соответствующего Item; на листе персонажа карточка показывает сохранённые значения, а нажатие на название открывает Item. При первом открытии листа данные карточек предыдущей версии переносятся в Items.
- Карточки Items на листе персонажа можно перетащить за значок в правом верхнем углу, чтобы изменить порядок внутри раздела. Рядом находится значок удаления карточки с актёра.
- Дополнительные блоки включаются в настройках системы Foundry: «Правила мира: Магия», «Воля», «Радиация», «Заражение», «Уровень стресса».
- Лист поддерживает светлую и тёмную темы Foundry.

Файл `point-zero-character-sheet.html` показывает компоновку и позволяет переключать темы без запуска Foundry. Это визуальный предпросмотр; игровые данные в нём не сохраняются.
